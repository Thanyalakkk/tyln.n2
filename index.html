วิธีนำไฟล์นี้ไปทำเว็บไซต์บน GitHub Pages

ไฟล์นี้เป็น HTML แบบ Single-File สมบูรณ์ สามารถเซฟเป็น index.html แล้วอัปโหลดใช้งานได้ทันที!
  1. สร้าง Repository บน GitHub:

    เข้า GitHub.com แล้วสร้าง Repository ใหม่ (ตั้งชื่อเช่น my-portfolio)

  2. อัปโหลดไฟล์ index.html:

    ดาวน์โหลดโค้ดนี้ บันทึกไฟล์ชื่อ index.html แล้วกด Add File -> Upload files เข้าใน Repository นั้น

  3. เปิดใช้งาน GitHub Pages:

    ไปที่เมนู Settings -> Pages -> เลือก Branch เป็น main หรือ master แล้วกด Save

  4. เสร็จสิ้น!

    รอประมาณ 1-2 นาที GitHub จะสร้าง URL เว็บไซต์ของคุณ เช่น https://yourusername.github.io/my-portfolio
